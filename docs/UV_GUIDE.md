# Using uv with This Project

This project supports [uv](https://github.com/astral-sh/uv), an extremely fast Python package installer and resolver written in Rust.

## Why uv?

- ⚡ **10-100x faster** than pip
- 🔒 **Reproducible builds** with uv.lock
- 🎯 **Automatic virtual environment** management
- 💾 **Global cache** - install once, reuse everywhere
- 🛠️ **Drop-in replacement** for pip

## Installation

### Install uv

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Or with Homebrew
brew install uv

# Or with pip
pip install uv
```

## Quick Start

### 1. Install Dependencies

```bash
# This creates .venv and installs all dependencies
uv sync
```

That's it! uv automatically:
- Creates a virtual environment in `.venv/`
- Installs all dependencies from `pyproject.toml`
- Generates `uv.lock` for reproducible builds

### 2. Run Code

**Option A: Use `uv run` (recommended)**

```bash
# Run any Python script
uv run python examples/01_basic_agent.py

# Run pytest
uv run pytest

# Run any command
uv run python -m src.agents.video_agent
```

**Option B: Activate the environment**

```bash
# Activate
source .venv/bin/activate  # macOS/Linux
# or
.venv\Scripts\activate  # Windows

# Now run normally
python examples/01_basic_agent.py
pytest
```

## Common Commands

### Install/Update Dependencies

```bash
# Sync with pyproject.toml (install/update)
uv sync

# Install with dev dependencies
uv sync --all-extras

# Update all packages
uv sync --upgrade
```

### Add New Dependencies

```bash
# Add a package
uv add package-name

# Add a dev dependency
uv add --dev package-name

# Add with version constraint
uv add "package-name>=1.0.0"
```

### Remove Dependencies

```bash
uv remove package-name
```

### Run Commands

```bash
# Run Python
uv run python script.py

# Run with arguments
uv run python script.py --arg value

# Run pytest
uv run pytest tests/

# Run specific test
uv run pytest tests/test_youtube_tools.py -v
```

### Other Useful Commands

```bash
# Show installed packages
uv pip list

# Show package info
uv pip show package-name

# Check for issues
uv pip check

# Export requirements
uv pip freeze > requirements.txt
```

## Project Structure with uv

```
video-to-book/
├── pyproject.toml       # Project config & dependencies
├── uv.lock             # Lock file (commit this!)
├── .venv/              # Virtual environment (auto-created)
├── src/                # Your code
└── tests/              # Your tests
```

## Key Files

### pyproject.toml

Defines your project and dependencies:

```toml
[project]
name = "video-to-book"
version = "0.1.0"
dependencies = [
    "langgraph>=0.2.0",
    "langchain>=0.2.0",
    # ... more dependencies
]

[project.optional-dependencies]
dev = [
    "pytest>=7.4.0",
    "black>=23.0.0",
    # ... dev tools
]
```

### uv.lock

Lock file ensuring everyone gets the same versions:
- **Commit this file** to git
- Auto-generated by `uv sync`
- Ensures reproducible builds

## Comparison: uv vs pip

### Installing Dependencies

**With pip:**
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Takes 30-60 seconds
```

**With uv:**
```bash
uv sync
# Takes 2-5 seconds ⚡
```

### Adding a Package

**With pip:**
```bash
pip install new-package
pip freeze > requirements.txt  # Manual step
```

**With uv:**
```bash
uv add new-package
# Automatically updates pyproject.toml and uv.lock
```

### Running Code

**With pip:**
```bash
source venv/bin/activate  # Must activate first
python script.py
```

**With uv:**
```bash
uv run python script.py  # No activation needed
```

## Tips & Tricks

### 1. Global Cache

uv caches packages globally, so installing the same package in multiple projects is instant:

```bash
# First project
cd project1
uv sync  # Downloads packages

# Second project with same dependencies
cd ../project2
uv sync  # Instant! Uses cache
```

### 2. Lock File Benefits

The `uv.lock` file ensures everyone on your team gets identical dependencies:

```bash
# Developer A
uv sync  # Installs exact versions from uv.lock

# Developer B (different machine)
uv sync  # Gets EXACT same versions
```

### 3. Faster CI/CD

In GitHub Actions or other CI:

```yaml
- name: Install dependencies
  run: |
    curl -LsSf https://astral.sh/uv/install.sh | sh
    uv sync
  # Much faster than pip!
```

### 4. Python Version Management

uv can also manage Python versions:

```bash
# Install specific Python version
uv python install 3.11

# Use specific version
uv python pin 3.11
```

## Troubleshooting

### "uv: command not found"

Install uv first:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Then restart your terminal or run:
```bash
source ~/.bashrc  # or ~/.zshrc
```

### Lock file out of sync

If you manually edit `pyproject.toml`:
```bash
uv lock  # Regenerate lock file
uv sync  # Install updated dependencies
```

### Clear cache

If you have issues:
```bash
uv cache clean
uv sync
```

### Use pip instead

You can always fall back to pip:
```bash
pip install -e .
```

## Migration from pip

If you're used to pip, here's the mapping:

| pip command | uv equivalent |
|-------------|---------------|
| `pip install package` | `uv add package` |
| `pip install -r requirements.txt` | `uv sync` |
| `pip install -e .` | `uv sync` |
| `pip list` | `uv pip list` |
| `pip show package` | `uv pip show package` |
| `pip freeze` | `uv pip freeze` |
| `pip uninstall package` | `uv remove package` |
